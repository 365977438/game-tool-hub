Anthropic 限制 Claude 克隆现有游戏，原创生成仍获保留

Anthropic 已调整 Claude Code 的提示词，减少模型生成现有游戏具体复刻或克隆版本的请求，以降低知识产权风险；原创游戏、类型游戏以及基于用户自有设计和素材的开发仍可继续使用该工具。

💡 Claude 正在限制克隆现有游戏，但并未封堵 AI 辅助原创游戏开发的路径。

关键要点

  • 收紧现有游戏克隆请求，降低知识产权风险
  • 保留原创游戏与类型游戏的 AI 生成能力
  • 使用自有素材仍可继续借助 Claude 开发
  • 建立资产来源与生成记录应对版权审查

正文（AI 核查整理）

Anthropic 正在收紧 Claude Code 对游戏生成请求的处理。此前，大量用户借助生成式 AI 制作现有游戏的仿制版本，甚至出现带有异常六指角色等明显质量问题的复刻作品。这类内容可能侵犯第三方系列或作品的知识产权，也给使用模型和代码工具的开发者带来潜在风险。

据 Anthropic 员工 Addy Osmani 表示，团队在 Claude Code 的 Opus 5.5 提示词中增加了两句话，引导模型避免重新创建“别人某款具体游戏”。这一调整针对的是已有作品的高度模仿，而不是全面禁止 AI 参与游戏制作。

Anthropic 明确表示，使用开发者自己的设计和素材构建游戏，以及生成原创游戏和类型游戏，仍应保持可用。这意味着 AI 生成游戏代码、原型资产和玩法实现的路径并未关闭，但模型对知名 IP 的直接复刻能力会受到更强限制。

对独立开发者和技术美术而言，工具选择需要从“能否模仿”转向“能否形成可辩护的原创工作流”。建议保留自有设计文档、资产来源和生成记录，并避免仅靠提示词要求模型复制具体角色、关卡或系列设定，以减少后续返工与版权争议。

这次限制也可能推动生成式 AI 工具从直接复刻竞品转向辅助原创机制、类型玩法和素材变体。模型仍可降低原型制作成本，但开发者必须把提示词、输入资产与最终产出之间的原创性控制纳入制作流程。
