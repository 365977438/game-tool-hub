Epic 详解 Claude Code 与 Codex 在游戏开发中的用法

Epic 披露正使用 Claude Code 与 Codex 协助开发，并承认存在“vibe coding”。案例包括减少长期困扰团队的随机烹饪 Bug，以及加速着色器压缩工作，显示生成式 AI 已进入引擎研发和 Fortnite 制作环节。

💡 Epic 给出具体用例：AI 不仅生成代码，还被用于治理烹饪 Bug 和加速着色器压缩。

  • 了解 Claude Code 与 Codex 的实际开发用途
  • 从可验证的 Bug 与性能任务开始试用
  • 建立生成代码的测试、审查和回滚机制

正文（AI 核查整理）

Epic Games 进一步说明其生成式 AI 应用方式，并明确表示公司正在使用 Claude Code 和 Codex 及其关联模型。Epic 管理层同时承认团队会进行“vibe coding”，显示其 AI 使用方式已经覆盖真实开发任务，而不只停留在营销表达层面。

据 Epic 介绍，AI 已用于广泛的开发工作，其中较具体的成果包括几乎消除长期存在的非确定性烹饪 Bug，以及加速着色器压缩相关工作。前者关系到运行时稳定性，后者则直接关联渲染管线效率，二者都比单纯生成代码更接近引擎与内容制作中的实际瓶颈。

对开发者而言，这类案例说明 AI 的价值不只在于快速生成代码，还可能用于追踪难以复现的问题、解释复杂系统和处理性能优化。但 Epic 强调更担心行动过慢，也意味着团队愿意承担更高验证与治理成本，以换取更快的迭代速度。

如果要复制这套方法，最好不要直接从生成大量代码开始，而应先选择结果可验证、失败可回滚的任务，例如测试生成、Bug 定位、脚本维护和着色器分析。团队应保存输入输出、运行自动化测试，并让熟悉引擎的工程师审查关键性能与稳定性改动。

趋势上，Claude Code、Codex 等工具正在成为制作流程中的新型工程层。独立开发者可借此缩小部分工具开发差距，技术美术则能重点评估着色器与性能工具的辅助效果。不过，效率提升必须建立在结果可复现、版本可追踪的基础之上。
