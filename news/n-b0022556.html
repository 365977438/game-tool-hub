Google Cloud 上线 Vera Rubin 基础设施

Google Cloud 宣布 NVIDIA Vera Rubin 基础设施即将正式商用，A5X 实例将面向智能体推理与大规模强化学习工作负载，并计划扩展至欧洲。对游戏开发者而言，这关系到智能体训练、行为模型训练和大规模仿真所需的云端算力。

💡 Vera Rubin 进入 Google Cloud，为 NPC 智能体训练和大规模强化学习提供新一代算力底座。

关键要点

  • 利用 A5X 开展智能体与强化学习训练
  • 评估大规模交互和仿真任务的云端成本
  • 关注欧洲区域的开放时间与实例支持
  • 先用小规模实验验证训练吞吐表现

正文（AI 核查整理）

Google Cloud 与 NVIDIA 宣布，搭载 NVIDIA Vera Rubin NVL72 系统的 A5X 实例即将正式商用，并计划于下月提供通用可用性，同时向欧洲扩展。面向游戏行业的价值主要体现在智能体、强化学习与大规模仿真等训练任务，而不是直接提供美术或内容生成工具。

A5X 将整合 Vera Rubin NVL72、ConnectX-9 SuperNIC、Google Cloud Virgo Network，以及 Google Cloud 第四代先进液冷技术，为智能体推理和大规模强化学习提供基础设施。强化学习需要持续经历生成经验、评估结果和更新模型的循环，因此训练平台必须覆盖完整链路。

对游戏开发者而言，这类基础设施可用于训练能够持续从交互中学习的智能体，也可支撑 NPC 行为模型、玩家建模和仿真环境等实验。素材没有给出具体游戏用例、性能指标或价格，因而现阶段更适合把它视为智能体训练基础设施升级，而非现成的 NPC 开发方案。

Google Cloud 计划把基于 Vera Rubin 的基础设施扩展至多个站点，最多部署 96 万颗 Rubin GPU。开发者可以关注欧洲区域的可用时间、实例获取方式、框架支持和实际成本，并先用小规模实验验证训练吞吐量，再决定是否迁移现有强化学习流程。

从行业趋势看，智能体训练正在推动算力需求从单纯模型推理扩展到持续交互与大规模经验生成。若云端平台进一步整合训练、评估和部署能力，游戏团队可能减少自建集群与工作流拼接的复杂度，但落地效果仍取决于任务适配和平台支持成熟度。
