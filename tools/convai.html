使用教程

入门⏱ 约 25 分钟🎯 做出一个可语音对话的 AI NPC 原型
  1. 1

    创建项目与 NPC 角色

    进入 Convai 官网注册并新建项目，在 Characters 页面点击 Create Character，填写角色名、背景故事、目标受众与说话风格，保存为可玩 NPC。

  2. 2

    配置智能体提示词

    打开角色详情，在 Prompt 或 Character Prompt 中写明身份、任务、语气、知识和禁区，并用示例对话约束回复格式；明确 NPC 不应替玩家做决定。

  3. 3

    接入对话与上下文

    在 Integrations 或 API 页面选择引擎，填写游戏运行环境、角色标识及上下文变量，复制 Character ID、API Key 等参数，区分公开密钥与后端密钥。

  4. 4

    启用语音交互

    进入 Voice 设置，选择预设或自定义音色，调整语速、音高与停顿；上传或录制角色台词作为开场语音，并确认输入设备、输出设备和权限正常。

  5. 5

    导入游戏引擎并测试

    按 Convai 文档安装 Unity、Unreal 或网页 SDK，将角色 ID 和鉴权信息写入角色配置；在游戏场景放置 NPC，绑定触发区域、对话面板或麦克风按键。

  6. 6

    调试并导出可玩版本

    使用 Console 与 Dialogue Debugger 测试多轮记忆、语气、延迟和语音输出，记录异常输入及超时情况；修正提示词和参数后构建测试包。

💡 实用技巧

  • 先用文字对话验证角色，再开启语音
  • 为关键回复准备固定触发与降级文本
  • 把长背景拆成可检索知识条目
  • 用真实玩家语料测试误解和越界

⚠️ 常见坑

  • 不要把 API Key 写进客户端代码
  • 避免提示词同时要求多种人格
  • 语音延迟过高时先缩短上下文
