工具介绍

CosyVoice 是开源中文语音生成模型，支持零样本声音克隆、自然语言指令控制、跨语言合成与多种语音场景。它可把 NPC 台词、剧情旁白转成富有情绪的成品语音，替代逐句真人录制和反复返录。工具主要面向 Linux，需要自行配置推理环境，克隆他人声线应先获得授权。

使用教程

入门⏱ 约 30 分钟🎯 产出可直接导入游戏管线的角色对白音频
  1. 1

    安装并启动项目

    克隆 GitHub 仓库，按 README 创建 Conda 环境、安装依赖并启动 WebUI；首次进入先检查模型文件是否完整，优先使用官方预训练模型。

  2. 2

    准备角色参考音频

    选取角色 10—30 秒无噪声、无背景音乐的清晰录音，准备对应文本；将音频放入工作目录，确保内容与角色声线、语言和目标情绪一致。

  3. 3

    克隆声线并生成对白

    在 WebUI 的 Zero-shot 模式上传参考音频，填写待说台词后点击生成；先短句测试，确认音色、停顿与吐字，再用于正式剧本。

  4. 4

    添加情绪和风格指令

    在指令模式输入“用低沉、愤怒的语气说”等明确要求，并填写台词；避免同时要求冲突情绪，比较不同参数下的结果后选定版本。

  5. 5

    批量导出游戏语音

    将 CSV 或 JSON 中的角色名、台词、情绪、文件名整理为批处理格式，运行仓库推理脚本；按角色和场景分目录保存 WAV，统一采样率与命名。

  6. 6

    接入游戏资产管线

    把 WAV 转成项目采用的 OGG 或其他格式，写入资源目录并建立角色、台词、情绪到音频的映射；播放时按事件键调用对应资源。

💡 实用技巧

  • 参考音频优先使用单人干声
  • 先生成短句再批量处理
  • 台词标点直接影响停顿节奏
  • 文件名绑定角色与场景编号

⚠️ 常见坑

  • 背景音乐会干扰音色克隆
  • 多情绪指令冲突会降低稳定性
