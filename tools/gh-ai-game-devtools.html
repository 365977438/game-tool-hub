使用教程

入门⏱ 约 20 分钟🎯 产出一份可执行的 AI 游戏原型工具链
  1. 1

    打开资源中心

    访问 GitHub 仓库，进入 README 的工具分类区，先记录代码、图像、三维、动画、音视频及 LLM 方案入口。

  2. 2

    确定原型需求

    写清玩法、目标平台和首版范围，例如俯视角射击、Unity 实现、两分钟试玩，据此确定各环节所需产物。

  3. 3

    筛选组合工具

    逐类比较工具用途、部署方式和输入输出，优先选择能导出 PNG、GLB、WAV、MP4 或源码的方案。

  4. 4

    生成并整理素材

    用图像工具制作角色、场景和 UI，用三维或动画工具补充模型与动作；统一命名、尺寸、帧率后导入资产目录。

  5. 5

    接入玩法代码

    将 LLM 辅助生成的 C#、TypeScript 或其他语言代码放入项目，先实现移动、攻击、碰撞，再绑定前述素材。

  6. 6

    串联音视频并验证

    生成音效、配乐和过场视频，导入时间轴并校准时长；运行原型测试输入响应、素材兼容性和性能。

💡 实用技巧

  • 先做最小玩法，再扩充美术内容
  • 优先选择支持商用与本地部署的工具
  • 统一素材尺寸、命名和采样率
  • 每轮生成后保留提示词与版本

⚠️ 常见坑

  • 只看展示效果，忽略导出格式
  • 生成内容缺少授权或许可证
