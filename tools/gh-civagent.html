工具介绍

CivAgent 是基于大语言模型的拟人化智能体，可在策略游戏 Unciv 中充当数字玩家。项目聚焦让模型在持续决策的游戏环境中理解局面并采取玩家行动。

核心能力

  • 接入 Unciv 策略游戏环境
  • 基于大语言模型生成玩家行为
  • 模拟具有持续决策能力的数字玩家
  • 适合研究语言智能体策略行为

👍 优点

  • 将 LLM 智能体置于真实策略游戏环境中
  • 应用场景具体，便于观察模型决策

⚠️ 局限

  • 目前以 Unciv 为核心，应用范围较集中
  • 社区项目，文档与支持有限

典型使用场景

  • 让大语言模型自动参与 Unciv 对局
  • 研究 AI 玩家在策略游戏中的决策表现

使用教程

进阶⏱ 约 30 分钟🎯 运行一名由 LLM 驱动的文明玩家
  1. 1

    准备运行环境

    安装 Python、Git 与 Unciv，在终端克隆 CivAgent：git clone https://github.com/fuxiAIlab/CivAgent.git，然后进入仓库并按 README 创建虚拟环境、安装依赖。

  2. 2

    配置大语言模型

    复制项目提供的环境变量或配置文件模板，填入模型 API 地址、密钥、模型名称及超时参数；密钥只放本地环境变量，不要提交到 Git。

  3. 3

    设置文明与策略参数

    在 CivAgent 的智能体配置中选择文明、玩家名称和策略提示词，设定决策温度、行动频率等参数；先用默认文明验证完整链路。

  4. 4

    连接 Unciv 对局

    按项目说明启动 CivAgent 与 Unciv 服务，在 Unciv 中创建或载入对局，添加智能体玩家并填写其连接信息，确认双方使用同一端口与房间。

  5. 5

    运行并观察决策

    启动智能体进程，在终端日志中检查模型请求、状态解析和动作提交；进入游戏观察其完成采集、探索或建设，并核对回合是否推进。

  6. 6

    接入游戏开发管线

    将 CivAgent 作为外部对局服务接入测试框架，用固定种子和可复现配置批量评估决策质量，并将日志、动作与胜率结果写入你的实验管线。

💡 实用技巧

  • 先验证单回合，再运行完整文明
  • 限制输出结构，避免无效游戏动作
  • 记录提示词、模型版本与回合日志
  • 用固定种子做策略对比实验

⚠️ 常见坑

  • API 密钥误写入配置文件或提交仓库
  • 端口、文明名称或回合协议不一致
