一个运行于 ComfyUI 的 MiniMax H3 Director 工作流项目，提供多语言工作流配置，主要用于组织与复用基于该模型的生成流程。具体节点能力需以仓库实现为准。

  • 提供 ComfyUI 工作流
  • 围绕 MiniMax H3 Director 编排
  • 支持多语言使用
  • 便于复用既有生成流程

👍 优点

  • 多语言配置便于不同团队使用

⚠️ 局限

  • 功能边界受仓库工作流实现限制
  • 社区项目，文档与支持有限

典型使用场景

  • 搭建游戏宣传视觉生成流程
  • 复用角色或场景概念图工作流

使用教程

入门⏱ 约 30 分钟🎯 产出首张游戏概念图并接入资产管线
  1. 1

    安装 ComfyUI 与自定义节点

    先按官方文档安装并启动 ComfyUI，再打开 Manager，搜索 ComfyUI_MiniMaxH3_Director 并安装；重启后检查节点菜单是否出现 MiniMax H3 相关分类。

  2. 2

    配置模型与运行环境

    打开仓库 README，下载或准备 MiniMax H3 所需模型与运行组件，按说明放入对应目录。回到 ComfyUI 检查模型路径、显存和推理设备，缺项先补齐。

  3. 3

    导入导演工作流

    从 GitHub 下载示例工作流 JSON，在 ComfyUI 中选择“工作流→打开”，载入文件；同时确认节点未标红，按 README 补齐模型、提示词或参数输入。

  4. 4

    编写游戏视觉指令

    在语言、导演指令或提示词节点中填写题材、视角、光照、风格和镜头运动，例如“俯视角废土城镇，模块化建筑”。使用多语言描述时保持字段含义明确，避免互相冲突。

  5. 5

    运行并筛选首张成果

    先使用示例参数点击“运行”，等待队列生成图片；再逐项调整角色一致性、构图、种子与镜头描述，保留满意结果并保存 PNG 与对应工作流。

  6. 6

    接入游戏资产管线

    按角色、场景、道具建立目录，将概念图和分镜按统一命名归档；在引擎或美术流程中生成参考图、遮罩或底图，并通过版本控制记录提示词、种子和工作流。

💡 实用技巧

  • 先用仓库示例跑通，再改提示词
  • 固定种子便于对比和复现
  • 概念图与分镜分开批量生成
  • 保留提示词、种子和工作流文件

⚠️ 常见坑

  • 模型路径错误会导致节点加载失败
  • 显存不足时先降低批量或分辨率
