工具介绍

GaussianDreamer 是华中科技大学团队开源的文本到三维生成项目，通过桥接二维和三维扩散模型快速生成三维高斯表示。该方法适合用于研究 AI 驱动的三维场景与资产快速构建。

核心能力

  • 支持文本到三维生成
  • 采用三维高斯作为场景表示
  • 桥接二维与三维扩散模型
  • 主打快速生成流程

👍 优点

  • 强调从文本到三维的快速生成
  • 研究发表于 CVPR 2024

⚠️ 局限

  • 生成内容的后处理与资产规范需额外处理

  • 根据文本描述生成高斯表示资产

使用教程

进阶⏱ 约 30 分钟🎯 生成一个可预览并导入引擎的三维高斯场景
  1. 1

    准备运行环境

    克隆 GitHub 仓库并阅读 README，按项目要求安装 Python、PyTorch、CUDA 和相关依赖；建议使用支持显卡加速的 Linux 或 Windows 环境。

  2. 2

    配置模型与权重

    下载 README 指定的二维、三维扩散模型权重及高斯生成所需文件，按照目录结构放置，随后复制配置文件并修改本地模型、数据和输出路径。

  3. 3

    编写场景提示词

    在项目提供的文本提示配置中描述场景，明确主体、数量、材质、风格和光照；首次测试先用简单场景，避免同时堆叠过多细节。

  4. 4

    运行三维生成

    执行 README 给出的推理命令，指定配置文件、提示词和输出目录；观察终端日志确认模型加载、采样与高斯优化均已完成。

  5. 5

    检查生成产物

    在输出目录查找点云、PLY 或项目支持的场景文件，使用仓库可视化脚本打开，检查主体轮廓、材质、视角和明显噪点，并按需调整提示词重跑。

  6. 6

    接入游戏引擎

    将 PLY 高斯资产转换为引擎可读取的格式或使用对应插件导入 Unity、Unreal；先放置于原型关卡，验证尺度、碰撞、材质与实时帧率，再决定是否精修。

💡 实用技巧

  • 提示词先写主体，再补风格与环境
  • 先做低分辨率测试缩短迭代时间
  • 生成后重点检查视角和边缘噪点
  • 引擎内先验证性能再投入美术精修

⚠️ 常见坑

  • 模型路径或权重版本不匹配会加载失败
  • 直接导入高密度PLY容易造成帧率骤降
