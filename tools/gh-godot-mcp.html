使用教程

入门⏱ 约 20 分钟🎯 用 AI 创建并运行一个 Godot 2D 场景
  1. 1

    准备 Godot 与 AI 客户端

    从 Godot 官网安装 4.x 编辑器，并准备支持 MCP 的 AI 客户端。进入项目目录，确认客户端可读取本地文件且能执行 Godot 命令。

  2. 2

    安装并配置 MCP 服务

    打开 Coding-Solo/godot-mcp 仓库，按 README 将服务加入 AI 客户端的 MCP 配置。填写 Godot 可执行文件路径，保存后重启客户端或重载 MCP。

  3. 3

    创建项目并建立连接

    新建一个 Godot 2D 项目，例如 game-demo。让 AI 客户端打开该项目目录，发送“检查 Godot 连接”类请求，确认工具列表中出现启动编辑器、运行项目等能力。

  4. 4

    让 AI 生成首个场景

    告诉 AI“创建一个 2D 场景，加入背景、玩家节点和 WASD 移动脚本，并保存到 scenes”。检查生成文件，确认脚本已挂到角色节点，避免只生成未挂载的代码。

  5. 5

    启动并运行项目

    在客户端中调用启动 Godot 编辑器或运行项目工具，打开生成的主场景。观察画面和输入反馈，再让 AI 修改移动速度、颜色或界面文字。

  6. 6

    读取日志并纳入管线

    让 AI 捕获并整理 Godot 调试输出，根据报错修改脚本后再次运行。最终将场景、脚本及可运行项目保留在版本控制中，作为后续游戏开发的输入产物。

💡 实用技巧

  • 项目目录与 MCP 工作目录保持一致
  • 先让 AI 列出节点和挂载关系
  • 每次只改一个小功能便于排错
  • 主场景和资源路径使用相对路径

⚠️ 常见坑

  • Godot 路径填错会导致 MCP 无法启动
  • 只生成脚本未挂载节点不会生效
