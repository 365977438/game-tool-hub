使用教程

进阶⏱ 约 30 分钟🎯 生成带对白与角色音色的可播放原型
  1. 1

    获取项目与检查环境

    打开 GitHub 的 izwi-ai/izwi，查看 README、Release 和示例配置；准备 Python、模型依赖及可用磁盘空间，按仓库说明创建运行环境。

  2. 2

    启动本地服务

    根据 README 配置模型路径、端口和设备，使用项目提供的启动命令运行服务；先访问健康检查或示例页面，确认接口能够响应。

  3. 3

    接入语音转录

    调用兼容 OpenAI 的转录接口上传角色录音，指定语言并查看返回文本；游戏事件日志中的语音可提交识别，结果写入字幕或对话状态。

  4. 4

    分离多名说话人

    在支持说话人分离的转录请求中开启相关选项，检查返回的说话人标签与时间戳；用 segment 字段映射 NPC、旁白等角色，生成对白轨。

  5. 5

    合成并克隆角色语音

    在文本转语音接口提交台词、角色参考音频和克隆参数，预览输出音频；统一采样率、响度及文件命名后，放入角色语音资源目录。

  6. 6

    串入游戏播放管线

    用服务返回的音频 URL 或文件替换临时下载文件，在游戏事件触发时调用 TTS，并把字幕、角色 ID 与音频路径一起写入资源清单，形成可播放原型。

💡 实用技巧

  • 先用短句和单人录音验证效果
  • 固定模型版本便于复现结果
  • 缓存重复台词可降低延迟
  • 按角色拆分音频资源目录

⚠️ 常见坑

  • 参考音频质量差会导致音色不稳
  • 转录时间戳需与游戏时间轴校准
