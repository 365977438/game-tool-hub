使用教程

入门⏱ 约 30 分钟🎯 获得一个可导入引擎的三维角色原型
  1. 1

    准备项目与运行环境

    克隆 GitHub 仓库，读取 README 的硬件要求与安装说明；创建 Conda 或虚拟环境，安装依赖并下载模型权重。若需 GPU，确认显存满足项目配置。

  2. 2

    启动角色生成界面

    按仓库文档运行启动脚本，在浏览器打开本地地址。进入文本生成页面后，先使用默认模型和参数测试，确保上传、生成与下载功能正常。

  3. 3

    编写游戏角色提示词

    在提示词框描述角色类别、性别外观、年龄、服装、材质和风格，例如“奇幻女猎人，轻甲，皮革与金属材质”。避免互相冲突的描述。

  4. 4

    调整参数并生成角色

    根据界面选项设置分辨率、随机种子、视角或采样参数，点击生成按钮并等待结果。检查轮廓、面部、服装结构和材质，保留满意版本并导出模型。

  5. 5

    整理模型与贴图资产

    将下载的网格、材质和贴图放入统一目录，并使用 Blender 打开模型；检查比例、法线、UV、贴图连接及骨骼，再按引擎规范修正坐标轴和单位。

  6. 6

    导入游戏引擎验证

    在 Unity 或 Unreal 中创建角色资产，导入网格并连接材质贴图，添加基础骨骼动画或临时控制器。通过游戏视图检查比例、材质和碰撞体，完成可玩原型。

💡 实用技巧

  • 先用默认参数跑通完整流程
  • 固定随机种子便于比较提示词
  • 提示词重点写清服装与材质
  • 生成后先检查 UV 和比例

⚠️ 常见坑

  • 显存不足时降低分辨率或分步生成
  • 不要直接把生成网格当最终资产
