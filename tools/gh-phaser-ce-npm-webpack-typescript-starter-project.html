使用教程

入门⏱ 约 30 分钟🎯 运行一个可构建和打包的 Phaser CE 项目
  1. 1

    准备开发环境

    安装 Node.js、npm 与 Git，确认终端可执行 node -v 和 npm -v；建议使用模板要求的较新 Node.js LTS 版本。

  2. 2

    获取项目模板

    打开 GitHub 仓库，点击 Code 后复制 HTTPS 地址；在终端执行 git clone，将仓库下载并切换到项目目录。

  3. 3

    安装项目依赖

    进入仓库根目录执行 npm install，等待 npm 按 package.json 安装 Phaser CE、TypeScript、Webpack 及相关构建插件。

  4. 4

    启动开发构建

    执行 npm run dev 启动 Webpack 开发服务器，根据终端提示打开本地地址；修改 src 中场景代码后观察自动更新效果。

  5. 5

    创建并调试场景

    在 src 下新增或修改 Phaser 场景，导入 Phaser 并创建预加载、创建和更新函数；把图片等资源放入约定目录后在 preload 中加载。

  6. 6

    构建并打包

    执行 npm run build 生成发行版文件，再按仓库说明运行 Electron 打包命令；检查输出目录并部署网页版产物。

💡 实用技巧

  • 资源路径应与静态目录结构保持一致
  • 开发时留意浏览器控制台的加载错误
  • 提交前运行类型检查与发行构建
  • 字体可改用 Google Fonts 动态加载

⚠️ 常见坑

  • Node.js 版本过旧会导致依赖安装失败
  • 忽略资源目录配置会触发路径或跨域错误
