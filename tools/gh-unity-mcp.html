工具介绍

Unity MCP 是用于连接 Unity 编辑器与 AI 编程助手的开源项目，让开发者能够借助模型辅助检查工程、操作项目或执行开发任务。其重点是打通编辑器与外部 AI 工具，而不是独立生成美术、音频或游戏内容。

核心能力

  • 连接 Unity 编辑器与 MCP 客户端
  • 支持 AI 编程助手参与项目开发
  • 可辅助工程检查与编辑器操作
  • 采用可扩展的开源集成方式

👍 优点

  • 能接入现有 Unity 开发流程
  • 有助于减少重复的工程操作

⚠️ 局限

  • 实际能力取决于所接入的 MCP 客户端
  • 运行需要兼容的 Unity 与 AI 工具环境

典型使用场景

  • 让 AI 助手检查和修改 Unity 项目
  • 通过 MCP 辅助搭建编辑器自动化流程

使用教程

入门⏱ 约 20 分钟🎯 让 AI 通过 MCP 成功操控 Unity 编辑器
  1. 1

    准备 Unity 与 MCP 客户端

    安装 Unity Hub 和兼容版本的 Unity Editor，同时准备支持 MCP 的 AI 客户端；确认项目已创建并能在 Unity 中正常打开。

  2. 2

    克隆并安装 Unity MCP

    打开 GitHub 的 CoplayDev/unity-mcp 仓库，按 README 使用 Unity Package Manager 导入本地包，或克隆后通过 Add package from disk 选择 package.json。

  3. 3

    配置 MCP 服务

    依据仓库文档，在 AI 客户端的 MCP 配置中添加 unity-mcp 服务及启动命令；将路径、Python 环境和项目参数替换为本机实际值。

  4. 4

    连接并验证编辑器

    启动 Unity 项目并运行 MCP 服务，在客户端查看连接状态；向 AI 发送“获取当前场景对象”等指令，确认 Unity 响应。

  5. 5

    完成首个自动化任务

    让 AI 在场景中创建 Cube、设置位置和材质，或生成一个 C# 脚本；检查 Hierarchy、Inspector 与 Console，并保存项目。

  6. 6

    扩展项目工作流

    尝试批量管理 Prefab、更新场景对象、运行编辑器菜单任务；重要改动前建立 Git 提交，便于审查和回退。

💡 实用技巧

  • 先验证连接，再执行批量修改
  • 使用绝对路径避免服务启动失败
  • 为不同 Unity 项目配置独立客户端
  • 让 AI 修改后检查 Console 报错

⚠️ 常见坑

  • Python 依赖或环境变量未配置
  • Unity 版本与插件要求不兼容
