使用教程

入门⏱ 约 30 分钟🎯 产出一个可对话并能长期记忆的 NPC 原型
  1. 1

    创建项目与角色

    打开官网并注册账号，进入 Inworld Studio 新建项目；选择 NPC 模板，填写角色名称、背景故事、性格和说话风格，保存为“酒馆管家”。

  2. 2

    设定身份与安全边界

    在角色的 Purpose 与 Guardrails 中填写核心职责、可用知识及拒答范围；让 NPC 只回答世界观内容，避免提示泄露和越权行为。

  3. 3

    配置记忆与知识库

    在 Memory 或 Knowledge 区域导入世界观、剧情事实和角色台词；添加明确的记忆条目，并测试角色能否正确召回玩家曾透露的信息。

  4. 4

    定义目标驱动行为

    在 Goals、Intentions 或 Behavior 页面添加可判断完成条件的目标，例如提供线索并引导玩家；明确触发条件、行动顺序与失败处理。

  5. 5

    接入游戏运行时

    进入角色的 Runtime 或 API 页面，获取凭据与调用参数；在游戏客户端的 NPC 对话接口中传入角色 ID、会话 ID 和玩家输入，接收并显示回复。

  6. 6

    联调并导出角色

    使用 Playtest 或测试控制台模拟多轮对话，验证记忆命中、目标推进及异常输入；修正人设和知识后，发布角色并保存接口配置。

💡 实用技巧

  • 用稳定会话 ID 保持玩家记忆
  • 重要剧情事实写成清晰条目
  • 给目标添加可验证的完成条件
  • 先做单人短对话再接复杂系统

⚠️ 常见坑

  • 新建会话会丢失连续记忆
  • 知识与角色设定冲突会导致混乱
