使用教程

入门⏱ 约 90 分钟🎯 成功编译并运行首个 Vulkan 示例
  1. 1

    创建学习账号并选择路径

    打开 learn.khronos.org，注册或登录账号；在学习目录中选择 Introduction to Vulkan，按 Introduction、Prerequisites、First App 等章节顺序学习。

  2. 2

    准备开发环境

    根据 Prerequisites 页面安装 Git、CMake、编译器和 Vulkan SDK；检查系统是否支持 Vulkan 1.3，并记录显卡驱动与 SDK 版本。

  3. 3

    获取官方示例

    进入教程提供的 GitHub 仓库链接，使用 git clone 克隆源码；进入项目目录，查看 README 中的依赖、构建命令及运行参数。

  4. 4

    配置并编译项目

    按系统打开 CMake 或 Visual Studio 工程，确认 SDK 路径和目标平台；若生成失败，先安装缺失依赖，再重新配置并编译。

  5. 5

    运行并验证首个窗口

    从构建输出目录启动可执行文件，观察是否出现旋转三角形；验证 Esc 退出、窗口缩放和基础交互，并对照预期结果排查异常。

  6. 6

    完成练习并继续进阶

    依次完成章节内测验与代码练习，阅读 Command Buffers、Render Pass、Pipeline 等后续主题；记录关键概念，再尝试修改顶点或渲染流程。

💡 实用技巧

  • 按章节顺序学习，避免跳过前置知识
  • 先跑通官方示例，再修改源码
  • 保留环境变量和构建日志便于排错
  • 结合 API 文档理解代码调用

⚠️ 常见坑

  • 显卡驱动过旧会导致设备不可用
  • SDK 路径或依赖缺失会编译失败
