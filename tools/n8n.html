使用教程

入门⏱ 约 30 分钟🎯 建立可运行的 AI 游戏资产管线
  1. 1

    安装并启动 n8n

    打开 n8n.io，按部署说明使用 n8n Cloud，或在本地安装 Docker Desktop 后运行官方容器。进入工作区，确认编辑器与节点面板可用。

  2. 2

    配置模型与素材服务

    点击右上角凭据管理，新增 OpenAI、Anthropic 等模型服务及云盘、数据库凭据。用测试凭据验证连接，并统一约定资产命名与状态字段。

  3. 3

    创建资产生成工作流

    新建工作流，添加 Manual Trigger、表单或 HTTP Request 输入节点，再接入 AI Agent 或文本生成节点。设置游戏类型、风格、尺寸等提示词参数。

  4. 4

    解析并保存生成产物

    在 AI 节点后添加代码节点，解析模型输出中的图片、模型或文本地址。连接数据库、对象存储或 GitHub 节点，写入资产 ID、路径、提示词和版本。

  5. 5

    加入条件与人工审核

    添加 IF 节点检查生成结果、文件格式和内容安全状态；不合格则回到重试节点，合格则进入审核。发送 Slack、表单或邮件通知，等待人工确认。

  6. 6

    触发游戏交付流程

    在审核节点后连接导出节点，将确认资产写入游戏项目目录、资源清单或构建仓库。用 Webhook 定时触发测试，运行完整流程并检查最终产物。

💡 实用技巧

  • 提示词与参数统一存入配置表
  • 为每件资产记录模型、种子和版本
  • 用测试素材先验证分支逻辑
  • 为失败任务设置重试与告警

⚠️ 常见坑

  • 不要把 API 密钥直接写进提示词节点
  • 云端文件地址需处理过期与访问权限
