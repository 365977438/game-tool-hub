使用教程

入门⏱ 约 30 分钟🎯 生成首件游戏素材并接入自动化管线
  1. 1

    注册并获取 API Token

    打开 replicate.com 注册登录，进入账户设置中的 API Tokens，点击创建 Token。妥善保存密钥，后续在本地环境变量中配置，避免写入公开仓库。

  2. 2

    选择适合游戏的模型

    在 Explore 中搜索 image、text-to-image、3D 或游戏素材相关模型，查看示例、输入参数、许可证与运行价格。首选支持图片输入或固定尺寸输出的模型。

  3. 3

    在线生成首个资产

    打开模型详情页，在 Input 填写提示词并设置尺寸、采样步数等参数，点击 Run。比较生成结果，记录效果较好的提示词、参数及模型版本。

  4. 4

    通过 REST API 批量生成

    参考模型页面的 API 示例，用 Authorization Bearer 头提交输入并轮询 prediction 状态。成功后下载输出地址，再将结果写入角色、道具或场景素材目录。

  5. 5

    接入游戏资产生成管线

    把模型调用封装为独立服务或编辑器工具，接收角色描述、风格和尺寸参数，异步生成后回传文件 URL。配合清单队列实现批量生成、重试与人工审核。

  6. 6

    微调并部署专属版本

    若需统一画风，在模型页启动 Training，准备已授权的数据集并配置训练参数。训练完成后固定模型版本，设置私有访问或硬件实例，再替换管线中的模型标识。

💡 实用技巧

  • 固定模型版本，避免升级后输出变化
  • 提示词与参数一起存入资产清单
  • 批量任务使用队列、缓存和重试
  • 发布前核对模型许可与商用范围

⚠️ 常见坑

  • 不要把 API Token 提交到代码仓库
  • 生成图需统一尺寸、命名和版权来源
