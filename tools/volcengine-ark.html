使用教程

入门⏱ 约 30 分钟🎯 用脚本批量生成并保存游戏素材
  1. 1

    开通模型推理服务

    进入火山引擎方舟控制台，依次点击“开通服务”“模型广场”，选择文本或视觉模型并确认开通；随后进入“API 密钥”，创建密钥并妥善保存。

  2. 2

    确认模型与调用参数

    在模型广场查看模型 ID、支持模态、上下文长度和计费规则；复制示例中的模型标识。图像任务需准备公网可访问的图片 URL，并明确提示词要求。

  3. 3

    安装客户端并配置凭证

    在本地项目目录运行 pip install volcengine-python-sdk[ark]，新建 Python 脚本；读取环境变量 ARK_API_KEY，不要把密钥直接写进代码或提交到 Git。

  4. 4

    调用文本或图像模型

    导入 Ark，创建客户端并调用模型：文本任务填写 messages，图像任务额外传 image_url；将提示词中的角色、场景、尺寸和风格写具体，先用单条请求验证输出。

  5. 5

    接入游戏素材批处理

    把道具描述、任务对白或角色设定整理为 JSON 清单；用循环并发提交请求，将结果写入 assets/ai-output，并同步保存模型名、提示词和任务编号。

  6. 6

    筛选产物并交付管线

    按格式、尺寸和内容约束过滤生成结果，将合格文本导入配置表、合格图片导入游戏资源目录；再把目录接入打包流程，形成可重复执行的批处理任务。

💡 实用技巧

  • 提示词固定角色、场景、画风和输出格式
  • 先测试十条再扩大批量规模
  • 缓存重复请求与已采用素材
  • 保留提示词和模型版本便于复现

⚠️ 常见坑

  • 不要把 API 密钥写入前端或仓库
  • 控制并发并检查限流与失败重试
