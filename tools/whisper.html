工具介绍

开源语音识别模型，可转写录音、生成字幕，并识别多种语言。适合给玩家访谈、角色台词、测试录音建立可检索文本，也便于后续字幕、翻译和配音流程。跨平台运行，实际效果受音质、噪声和口音影响。

核心能力

  • 自动生成时间轴字幕
  • 支持本地批量转写
  • 识别常见音频格式

👍 优点

  • 适合整理长段录音

  • 整理语音评测素材

使用教程

入门⏱ 约 20 分钟🎯 产出可编辑的转写文本和字幕文件
  1. 1

    准备音频与运行环境

    安装 Python 和 FFmpeg，把访谈、角色语音等素材统一放入 input 目录，建议使用 WAV 或 MP3，并确保文件名前缀带有版本号。

  2. 2

    安装 Whisper

    打开终端，执行 pip install -U openai-whisper，再运行 whisper --help 检查命令。首次运行会下载模型，网络环境需允许访问模型仓库。

  3. 3

    转写第一段录音

    执行 whisper input/interview.mp3 --model small --language zh --task transcribe --output_format all，生成文本、SRT、VTT 等文件，按素材编号保存到 output。

  4. 4

    批量处理素材

    将多段录音放入 input 后执行 whisper input --model small --language zh --task transcribe --output_format all；也可用 Python API 遍历文件，统一模型和输出目录。

  5. 5

    校对并接入管线

    对照原音频修正专有名词、角色名和时间轴，导出 JSON 或 SRT 到字幕目录；同时把纯文本送入检索、翻译或配音脚本流程。

  6. 6

    制作字幕与语音任务

    根据 SRT 时间码切分对白，导入剪辑、翻译或字幕工具；再用 TTS 工具生成角色语音，保留原音、转写文本、字幕三者的资产编号。

💡 实用技巧

  • 中文访谈先指定 zh，提升转写稳定性
  • 短句对白可加 initial_prompt 补全语境
  • 长音频分段转写后再合并时间轴
  • 模型越大通常越准，也更耗时耗显存

⚠️ 常见坑

  • FFmpeg 未加入 PATH 会导致读取失败
  • 直接覆盖转写结果会丢失人工校对
