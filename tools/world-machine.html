工具介绍

World Machine 是专业程序化地形制作工具，可通过节点式流程生成山脉、河流、侵蚀和高度图，并将结果用于游戏世界构建。它适合承接 AI 提出的地形概念或参数方案，再由美术进行精确塑造与引擎导入。目前主要支持 Windows，采用买断制。

使用教程

入门⏱ 约 30 分钟🎯 制作并导出一张带侵蚀细节的岛屿高度图
  1. 1

    安装并新建项目

    前往官网下载并安装 World Machine，启动后选择 Basic 模板，点击左上角 New，选择设备分辨率与地图尺寸，勾选 Height Output 后进入编辑界面。

  2. 2

    搭建基础高度场

    在 World 面板选中 Primary Layer，点击 Generate Fractal 按钮生成初始地形；用 Select 工具拖拽编辑区，调节缩放高度与细节噪声，形成山地和谷地。

  3. 3

    调整海岸与岛屿轮廓

    在 Layer 中添加 Radial 设备，把半径设为 2400、Shape 调为 Smooth，勾选 Invert 生成岛体；叠加第二个较小岛体，并用 Build 合并图层。

  4. 4

    加入水文侵蚀

    进入 Erosion 面板，从模拟类型中选择 Hydraulic Erosion，设置水流量、降雨量与沉积参数，点击 Simulate 预览侵蚀；满意后返回主视图确认沟谷。

  5. 5

    添加生物群系材质

    在 Terrain 面板添加 Biome 设备，为 Beach、Forest、Mountain 分配纹理或颜色；调整材质范围和高度规则，使不同地貌呈现清晰分区。

  6. 6

    导出引擎可用资产

    点击 Build 生成最终地形，在 Output 面板选择目标格式与分辨率；游戏项目通常导出 EXR 或 PNG 高度图及颜色贴图，再导入 Unity、Unreal 等引擎。

💡 实用技巧

  • 先做小尺寸预览，再提高分辨率
  • 侵蚀后叠加少量噪声可增加细节
  • 多个图层用 Build 统一合成
  • 为海平面预留明确高度范围

⚠️ 常见坑

  • 过强侵蚀会让地形变得破碎
  • 导出前检查位深与通道设置
