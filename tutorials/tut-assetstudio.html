AssetStudio 入门：提取 Unity 游戏资源

从下载安装到加载资源文件，逐步掌握 AssetBundle 解析及模型、贴图、材质、动画和音频的导出方法。

关联工具ASAssetStudio官网 ↗
入门⏱ 约 20 分钟🎯 成功提取并查看 Unity 游戏资源
  1. 1

    下载并安装工具

    打开 GitHub 项目页面，进入 Releases 下载适用于 Windows、macOS 或 Linux 的压缩包，解压后运行 AssetStudio。

  2. 2

    加载资源文件

    在主界面点击“Load file”或“Load folder”，选择 Unity 数据目录、AssetBundle 文件或资源文件夹，等待文件树解析完成。

  3. 3

    浏览资源结构

    在左侧资源树按类型或容器查找对象，右侧可预览模型、贴图、材质、动画及音频，缩略图双击通常会打开预览。

  4. 4

    筛选目标资源

    使用搜索框输入资源名称，并结合类型筛选定位目标；选中对象后查看右侧属性，确认路径与所属容器是否匹配。

  5. 5

    批量导出资源

    勾选需要导出的对象，点击“Export”并选择输出目录和格式；模型可优先尝试 FBX，贴图可选 PNG，音频按原类型导出。

  6. 6

    检查导出结果

    打开导出目录，检查文件是否完整；材质依赖贴图，动画依赖骨骼，若预览异常，可回到原文件树确认相关资源。

💡 实用技巧

  • 批量导出前先用搜索框缩小范围
  • 贴图预览蓝白格可能表示透明通道
  • 优先导出到按类型分开的目录
  • 保留原始文件树便于追踪依赖

⚠️ 常见坑

  • 资源较多时解析和导出耗时较长
  • 受版本或加密影响的文件可能无法读取

常见问题

Q：Windows、macOS 和 Linux 上怎么安装？

进入 GitHub 项目的 Releases 页面，下载与系统对应的压缩包，解压后运行 AssetStudio。不同系统需选择各自的发布包，不要下载或使用不适配当前系统的版本。

Q：提取出来的模型为什么预览或导出异常？

模型、材质和动画可能存在依赖关系。遇到异常时，先在右侧预览模型、贴图、材质及动画，并检查所选对象的路径和所属容器；材质需确认关联贴图，动画需确认关联骨骼。

Q：大量素材该怎样导出并分类保存？

先用搜索框按资源名称缩小范围，再结合类型筛选并勾选目标对象，点击 Export 选择输出目录。模型优先使用 FBX，贴图可选 PNG，音频按原类型导出，并建议按资源类型分开目录。
