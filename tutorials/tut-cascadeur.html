Cascadeur 入门：制作第一个角色动作

从下载安装、导入模型到制作跳跃与落地动作，并了解动画混合与引擎导出，助你快速生成自然流畅的角色动态。

关联工具CACascadeur官网 ↗
入门⏱ 约 30 分钟🎯 完成一个可导出的角色跳跃动作
  1. 1

    下载并安装软件

    打开 Cascadeur 官网，进入 Download 页面，选择 Windows、macOS 或 Linux 版本下载并安装；首次启动时按提示创建账号并设置工作目录。

  2. 2

    导入角色模型

    点击 File 菜单中的 Open，选择带骨骼的 FBX 或 glTF 模型导入；在 Outliner 中确认角色结构，然后点击 Fit Character，按提示设置身高与肢体比例。

  3. 3

    设置场景与初始姿势

    点击顶部的 Scene 按钮准备场景，使用 Character 模式调整角色站姿；启用 Physically Based 选项，并确认模型朝向、地面高度及重力学场设置正确。

  4. 4

    制作起跳动作

    在关键帧工具栏点击 Add Keyframe，分别选定脚掌、膝盖和髋部等控制点，在 Pose Mode 中摆出下蹲、蓄力与离地姿势；按空格预览并逐帧修正动作。

  5. 5

    添加落地与恢复

    复制关键帧并延长时间轴，手动调整双脚接触、膝盖弯曲和上身惯性；开启轨迹显示与动画辅助线，依据碰撞和重力效果微调落脚姿势。

  6. 6

    预览混合并导出

    在 Timeline 中设置动作片段与混合区域，通过 Animation Mixing 调整衔接；完成后使用 Export FBX 导出动画，勾选所需骨骼后在游戏引擎中测试播放。

💡 实用技巧

  • 先做短动作，再逐步延长与细化
  • 关键帧重点调整髋、膝和脚掌
  • 开启轨迹线检查运动弧度
  • 导出前确认骨骼命名与单位

⚠️ 常见坑

  • 角色比例未校准会导致动作异常
  • 直接套用动作容易出现脚底滑移

常见问题

Q：Windows、macOS 和 Linux 怎么安装？

进入 Cascadeur 官网的 Download 页面，按系统选择对应版本下载并安装。首次启动时，按提示创建账号并设置工作目录。

Q：导入的 FBX 或 glTF 角色为什么动作异常？

先在 Outliner 中确认角色结构，再点击 Fit Character，按模型实际体型设置身高和肢体比例。比例未校准会直接影响动作生成。

Q：导出到游戏引擎前要检查什么？

使用 Export FBX 导出动画，勾选所需骨骼，并确认骨骼命名、单位和动画片段设置。导出后放入游戏引擎测试播放，检查衔接与脚底滑移。
