ComfyUI-Manager 入门：让游戏美术资产自动进管线

完成 ComfyUI-Manager 安装、模型与节点管理，并用工作流批量生成可导入游戏项目的角色、场景和道具素材。

关联工具COComfyUI-Manager官网 ↗
入门⏱ 约 20 分钟🎯 批量产出可进入游戏美术管线的 AI 素材
  1. 1

    安装 ComfyUI 与 Manager

    启动 ComfyUI，复制官方仓库地址到 ComfyUI-Manager 的安装页面；按提示克隆到 custom_nodes，重启后确认节点菜单出现 Manager。

  2. 2

    检查模型与节点状态

    打开 Manager 的 Model Manager 与 Custom Nodes Manager，分别检查本地模型、节点版本和缺失依赖；先更新 Manager，再按兼容性逐项升级。

  3. 3

    安装生成所需节点

    在 Custom Nodes Manager 搜索并安装 Checkpoint Loader、ControlNet 或 IP-Adapter 等节点；安装后重启 ComfyUI，确认节点未显示红色缺失提示。

  4. 4

    同步并匹配模型资源

    进入 Model Manager 搜索基础模型、LoRA、VAE 和 ControlNet，按工作流要求同步到对应目录；注意同名模型版本，避免旧版文件覆盖。

  5. 5

    建立游戏素材工作流

    在 ComfyUI 画布连接模型加载、提示词、采样器、ControlNet 与 Save Image 节点；设置统一分辨率、批量数量和固定种子，生成角色立绘、场景图或道具图。

  6. 6

    把产物接入游戏管线

    生成后从 output 目录取回 PNG，按角色、场景、道具分类；保留提示词、模型名、种子与工作流 JSON，便于批量迭代并复现素材。

💡 实用技巧

  • 固定种子便于筛选同一角色的最佳版本
  • 批量生成前先用单张测试构图
  • 素材命名加入用途、尺寸和版本号
  • 工作流与提示词一起归档便于复现

⚠️ 常见坑

  • 安装节点后未重启，界面仍显示缺失
  • 模型放错目录，Manager无法正确识别

常见问题

Q：安装后菜单里没有 Manager 怎么办？

确认 ComfyUI-Manager 已克隆到 custom_nodes 目录，再完整重启 ComfyUI；随后检查节点菜单是否出现 Manager。若仍没有，重新核对仓库克隆位置和目录结构。

Q：Manager 找不到模型是放错目录了吗？

可能是模型未同步到对应目录。先在 Model Manager 搜索基础模型、LoRA、VAE 或 ControlNet，再按工作流要求同步到对应位置，并确认同名文件不是旧版本。

Q：怎样把生成素材接入游戏项目？

从 ComfyUI 的 output 目录取回 PNG，按角色、场景、道具分类保存；同时归档提示词、模型名、种子和工作流 JSON。命名可加入用途、尺寸与版本号，便于后续迭代。
