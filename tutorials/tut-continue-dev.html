Continue 入门：用 AI 完成首个游戏功能

从安装配置到上下文补全、项目聊天和局部改写，搭建可自建后端的 AI 游戏编码流程。

关联工具COContinue官网 ↗
入门⏱ 约 20 分钟🎯 用 AI 生成并接入一个可运行的游戏功能
  1. 1

    安装 Continue 扩展

    在 VS Code 左侧扩展面板搜索 Continue 并安装；若使用其他编辑器，先确认其兼容版本和配置方式。

  2. 2

    配置模型与后端

    打开 Continue 侧栏，在模型配置中填写 API 密钥、模型和接口地址；也可选择本地模型或自建兼容 OpenAI 格式的后端。

  3. 3

    建立游戏项目上下文

    用 Continue 的项目级聊天添加引擎、玩法和目录说明，让 AI 了解语言、框架、输入系统及代码规范，避免只生成孤立片段。

  4. 4

    生成并预览代码

    在游戏控制器或玩法脚本中描述需求，例如“实现玩家跳跃和二段跳”；查看补全候选，按 Tab 接受并用预览窗口或运行命令检查结果。

  5. 5

    选中代码进行改写

    选中需要修改的代码，通过聊天框输入明确指令，如“增加无敌帧并保持原输入逻辑”；确认差异后逐段接受，再运行游戏验证。

  6. 6

    接入开发与提交流程

    把 AI 生成代码按模块保存，执行格式化、测试和本地运行；通过 Git 查看差异，确认无敏感信息与破坏性改动后提交。

💡 实用技巧

  • 用配置文件说明项目结构和编码规范
  • 每次只改一个玩法或系统模块
  • 优先选择本地模型处理核心代码
  • 先保存 Git 提交再让 AI 改写

⚠️ 常见坑

  • 不要直接接受整文件生成结果
  • 接口地址与模型名称必须匹配

常见问题

Q：Continue 装好后，模型一直连接失败怎么办？

检查模型配置中的 API 密钥、模型名称和接口地址是否对应，同一后端的地址与模型名称必须匹配。可改用本地模型，或填写兼容 OpenAI 格式的自建后端地址后重新测试。

Q：VS Code 之外能用 Continue 做游戏开发吗？

可以，但要先确认目标编辑器是否有兼容版本，以及该版本采用的配置方式。配置模型与后端后，仍需提供项目级聊天、代码补全和局部改写所需的编辑器能力。

Q：没有游戏素材，能只靠 Continue 做出功能吗？

本教程只覆盖代码生成与接入，不包含素材制作或导出流程。可先让 AI 实现玩家跳跃、二段跳等玩法代码并完成预览验证；素材需按项目现有目录规范另行准备。
