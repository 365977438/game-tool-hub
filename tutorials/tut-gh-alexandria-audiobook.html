AI游戏有声书入门：从脚本到多角色配音

面向游戏开发者，演示如何导入剧本、让大模型标注角色与台词，再用克隆或设计声音生成多角色样片，并导出可直接接入项目管线的声音文件。

关联工具ALAlexandria Audiobook官网 ↗
进阶⏱ 约 45 分钟🎯 产出带角色配音的章节样片与可复用音频素材
  1. 1

    安装并启动项目

    打开 GitHub 仓库，按 README 安装 Python、模型依赖及音频工具，在项目目录运行启动命令；先确认 Web 界面或命令行服务能正常访问。

  2. 2

    准备脚本和角色表

    整理为“角色名：台词”的逐行文本，补充角色性别、年龄、语气与情绪；再准备一段干净参考录音，用于后续克隆声音。

  3. 3

    调用大模型标注脚本

    在脚本导入区提交文本，选择负责添加角色、情绪和朗读标注的模型，检查输出是否保留角色名；修正错标后再进入配音。

  4. 4

    配置声音或训练 LoRA

    克隆声音时上传参考音频并命名角色；设计声音时填写音色描述。追求稳定角色效果时，按文档准备样本并完成 LoRA 训练。

  5. 5

    生成并检查章节样片

    选择角色模型和逐行风格控制参数，先生成少量台词试听；重点检查发音、多人切换、情绪、停顿与响度，发现问题立即回改标注。

  6. 6

    导出并接入游戏管线

    按章节导出 MP3 或分章 M4B，需要后期编辑时导出 Audacity 多轨文件；把角色名、台词和文件路径写入项目资产清单供引擎调用。

💡 实用技巧

  • 先做三句试听，再批量生成整章
  • 角色名保持统一，避免模型误判
  • 参考录音优先使用单人干声
  • 响度检查应放在导出前完成

⚠️ 常见坑

  • 剧本格式混乱会导致角色错配
  • 直接生成整章会放大标注错误
