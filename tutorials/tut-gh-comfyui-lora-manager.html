LoRA 管理入门：从安装到接入工作流

面向游戏 AI 美术开发，讲解安装扩展、整理与预览 LoRA、读取元数据，并把模型接入 ComfyUI 工作流，产出可复用的游戏概念图。

关联工具COComfyUI LoRA 管理器官网 ↗
入门⏱ 约 20 分钟🎯 建立可用 LoRA 库并生成首张游戏概念图
  1. 1

    安装 ComfyUI 与扩展

    启动 ComfyUI，进入 Manager 的 Custom Nodes 页面，搜索 ComfyUI-LoRA-Manager 并安装；更新依赖后重启，确认节点菜单出现 LoRA 管理相关入口。

  2. 2

    配置模型目录

    在 ComfyUI 的 extra_model_paths.yaml 中填写 LoRA 文件夹路径并重启。也可直接放入 ComfyUI/models/loras，建议按游戏角色、风格和版本分类。

  3. 3

    整理并扫描 LoRA

    打开 LoRA 管理器，点击刷新或扫描模型库，勾选需要的 LoRA；同步维护名称、作者、触发词等元数据，方便按角色和风格快速筛选。

  4. 4

    预览模型效果

    在管理器中选择 LoRA 并点击预览，确认文件可正常加载；结合触发词、权重和参考图记录效果，为游戏角色或场景选定候选模型。

  5. 5

    接入工作流

    在节点库添加 LoRA Loader，连接 Checkpoint、CLIP 与 VAE；选择模型并设置 strength_model、strength_clip，保存为角色或场景资产工作流。

  6. 6

    生成游戏美术产物

    在采样节点输入游戏角色提示词与负面提示词，设置分辨率和采样参数后生成图片；筛选稳定结果，连同 LoRA、权重和工作流一起归档。

💡 实用技巧

  • 按角色、风格、版本建立 LoRA 子目录
  • 固定记录触发词与推荐权重
  • 先用小分辨率批量筛选候选模型
  • 把工作流和预览图一同版本管理

⚠️ 常见坑

  • 模型放错目录会导致扫描不到
  • 触发词或权重不匹配会破坏画面
