ComfyUI 工作流入门：生成游戏美术素材

面向游戏开发与美术人员，介绍如何安装依赖、导入示例工作流、替换提示词并批量生成可直接进入资产管线的图像素材。

关联工具COComfyUI-Yolain 工作流合集官网 ↗
入门⏱ 约 25 分钟🎯 生成并导出可用于游戏原画的图片素材
  1. 1

    安装 ComfyUI 与节点包

    先安装并启动 ComfyUI，进入 Manager 的 Custom Nodes 搜索 comfyui-easy-use 并安装；随后重启，确认节点菜单中出现 Easy-Use 分类。

  2. 2

    下载并导入工作流

    打开项目的 GitHub Releases 或工作流目录，下载带 workflow 名称的 JSON；回到 ComfyUI 工作区，拖入 JSON，或通过 Load 节点读取。

  3. 3

    配置模型与参数

    按示例中的 Checkpoint、LoRA、提示词和尺寸节点替换本地路径与内容。首次测试选用工作流支持的模型、较低分辨率，并检查采样器和步数。

  4. 4

    编写游戏美术提示词

    在正向提示词输入角色、场景、风格与构图，在负向提示词排除模糊、畸形和多手等问题；用游戏企划中的真实需求逐项修改描述。

  5. 5

    运行并筛选产物

    点击 Queue 执行，在输出节点预览结果，保存满意图片并记录对应参数。可调整随机种子、提示词和尺寸，形成风格一致的角色或场景系列。

  6. 6

    接入游戏资产管线

    按项目规范导出 PNG 或 WebP，统一命名并放入 source_art；再裁切、抠图或转成图集，导入引擎或贴图工具，验证分辨率、透明度和压缩质量。

💡 实用技巧

  • 先低分辨率跑通，再提升画质
  • 固定种子便于复现和迭代
  • 保存原始提示词与模型版本
  • 素材入库前统一尺寸和命名

⚠️ 常见坑

  • 漏装 Easy-Use 会导致节点标红
  • 模型路径或名称不匹配会加载失败

常见问题

Q：安装后找不到 Easy-Use 节点怎么办？

进入 ComfyUI 的 Manager，在 Custom Nodes 中搜索 comfyui-easy-use 并安装，完成后重启 ComfyUI，再检查节点菜单是否出现 Easy-Use 分类。

Q：工作流加载后模型显示错误怎么处理？

检查 Checkpoint 和 LoRA 节点中的本地路径及名称是否与实际文件一致，并确认使用的是该工作流支持的模型。首次测试可降低分辨率，先排除路径或模型不匹配问题。

Q：生成的图片如何整理并导入游戏项目？

先在输出节点保存满意图片并记录提示词、模型版本和种子，再按项目规范导出 PNG 或 WebP，统一命名并放入 source_art。裁切、抠图或制作图集后导入引擎或贴图工具，检查分辨率、透明度和压缩质量。
