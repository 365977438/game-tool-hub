Unity MCP 入门：用 AI 生成并验证游戏场景

从安装配置到执行编辑器代码，让 AI 创建场景、生成资源、模拟输入并截图验证，形成可迭代的游戏开发闭环。

关联工具FUFunplay Unity MCP官网 ↗
进阶⏱ 约 30 分钟🎯 用 AI 自动创建并验证一个 Unity 游戏场景
  1. 1

    准备 Unity 与 MCP 客户端

    安装兼容版本的 Unity Editor，并在支持 MCP 的 AI 客户端中添加 Funplay Unity MCP 服务；先打开项目，确认客户端能发现 Unity 工具。

  2. 2

    安装并连接 Unity 包

    按仓库 README 使用 Package Manager 或本地包方式安装插件，打开 Unity 后检查 Console；若无报错，在 MCP 客户端点击刷新并执行连接测试。

  3. 3

    让 AI 读取项目结构

    在客户端中要求 AI 列出当前场景、层级和脚本，避免凭空猜测项目；让它把分析结果保存为开发清单，作为后续生成提示词的上下文。

  4. 4

    执行代码创建场景

    通过 execute_code 发送经过确认的 C# 编辑器代码，批量创建对象、组件及 Prefab；先在测试场景执行，并要求 AI 汇报创建结果和资源路径。

  5. 5

    生成资源并接入管线

    让 AI 按项目规范制作材质、贴图或占位资源，将产物保存到 Assets 对应目录；再生成调用资源的脚本与场景配置，使资源真正进入运行流程。

  6. 6

    模拟运行并截图验收

    进入 Play Mode，通过 MCP 模拟移动、点击等输入并获取编辑器截图；把截图与报错交给 AI 修正逻辑，复测后保存可运行的场景或构建产物。

💡 实用技巧

  • 先让 AI 读取现有项目规范
  • 代码执行前先创建测试场景
  • 资源按 Assets 目录分类落盘
  • 每次修改后用截图和日志复验

⚠️ 常见坑

  • Unity 与 MCP 包版本不匹配
  • 批量改写前未备份场景和 Prefab

常见问题

Q：Unity 装好后客户端发现不了 MCP 工具怎么办？

先打开 Unity 项目并等待编辑器加载完成，再在 MCP 客户端刷新工具列表；若仍无法发现，核对 Unity Editor 与 Funplay Unity MCP 包是否兼容，并检查 Unity Console 是否有安装或连接报错。

Q：用 execute_code 前需要做哪些准备？

先让 AI 读取当前场景、Hierarchy 和脚本，再保存一份开发清单作为上下文；确认代码后，在独立测试场景中执行，并让 AI 汇报创建的对象、组件及资源路径，避免直接改坏现有场景。

Q：AI 生成的素材怎样真正接入游戏？

要求 AI 按项目规范生成材质、贴图或占位资源，并保存到 Assets 对应目录；随后让 AI 生成引用这些资源的脚本和场景配置，再进入 Play Mode 模拟输入，结合截图与报错验证资源已被运行流程使用。
