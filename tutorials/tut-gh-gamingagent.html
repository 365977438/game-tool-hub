GamingAgent 入门：评测你的第一个游戏智能体

从安装 Python 环境、接入模型到运行游戏任务，搭建一套可复现的 LLM 或 VLM 游戏智能体评测流程，并把结果用于模型选型与迭代。

关联工具GAGamingAgent 游戏智能体与评测框架官网 ↗
进阶⏱ 约 60 分钟🎯 跑通一个游戏任务并产出评测结果
  1. 1

    克隆项目并检查环境

    在终端执行 git clone https://github.com/lmgame-org/GamingAgent.git，随后阅读 README 的依赖与示例说明，确认 Python 版本，并创建独立虚拟环境。

  2. 2

    安装依赖并完成配置

    进入项目目录激活虚拟环境，安装 requirements 或项目指定的依赖包；复制环境变量模板，填入模型 API Key、游戏配置及任务参数，避免把密钥写入代码。

  3. 3

    接入 LLM 或 VLM 模型

    在模型配置中选择文本或多模态模型，填写模型名称、接口地址和推理参数；文本智能体处理观察与动作，VLM 智能体还需按文档准备截图或图像输入。

  4. 4

    选择游戏环境与任务

    按 README 提供的示例启动受支持游戏或环境，指定关卡、目标、动作空间和最大交互步数；首次先用内置示例验证模型、渲染与输入输出链路。

  5. 5

    运行智能体评测

    执行文档中的评测命令，加载刚才的配置文件并运行；重点观察每步观察、模型决策、动作执行、奖励或成功率，以及日志和结果文件的生成位置。

  6. 6

    汇总结果并接入研发管线

    比较不同模型或提示词在相同任务上的成功率、步数和资源消耗，将结果表、轨迹日志与复现配置纳入 CI 或实验系统，再依据失败轨迹迭代智能体策略。

💡 实用技巧

  • 先用官方最小示例跑通全链路
  • 固定随机种子与模型参数便于复现
  • 同时记录决策日志和游戏截图
  • 评测集与开发任务应分开维护

⚠️ 常见坑

  • 未安装图形依赖导致环境无法启动
  • 多模态截图格式或尺寸不匹配

常见问题

Q：虚拟环境创建后，依赖应该怎么安装？

进入 GamingAgent 项目目录并激活独立虚拟环境，再按 README 安装 requirements 或项目指定的依赖包。安装后先运行内置最小示例，确认 Python 版本、游戏环境、模型调用和结果输出均正常。

Q：模型配置完成后，如何验证接口能正常调用？

在模型配置中填写模型名称、接口地址和推理参数，并通过环境变量模板配置 API Key。先选择文本模型运行内置任务；使用 VLM 时还需按文档准备截图或图像输入，检查格式和尺寸是否匹配。

Q：评测结束后，哪些结果可以接入研发管线？

汇总成功率、交互步数和资源消耗，并保留每步观察、模型决策、动作执行、奖励、轨迹日志及游戏截图。将结果表、日志和复现配置一并纳入 CI 或实验系统；复现时应固定随机种子与模型参数。
