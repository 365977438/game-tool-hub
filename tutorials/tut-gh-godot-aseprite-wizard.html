Godot Aseprite 向导入门指南

从安装向导、配置 Aseprite 路径到导入精灵动画，演示 AnimationPlayer、AnimatedSprite 与 SpriteFrames 的实际用法。

关联工具GOGodot Aseprite 向导官网 ↗
入门⏱ 约 20 分钟🎯 成功导入并播放 Aseprite 动画
  1. 1

    安装向导与 Aseprite

    打开项目仓库的 Releases 下载并解压插件，将目录复制到 Godot 项目的 addons 目录；同时准备已安装的 Aseprite。

  2. 2

    启用插件并配置路径

    在 Godot 的项目设置中找到插件选项，启用 Godot Aseprite Wizard，再进入其设置，指定 Aseprite 可执行文件并确认保存。

  3. 3

    准备 Aseprite 动画

    在 Aseprite 中逐帧绘制并保存为 PNG 图集或精灵表，导出对应的 JSON 文件；文件名、图层和帧数据保持默认规范。

  4. 4

    导入动画资源

    回到 Godot 文件系统，选中 PNG 与配套 JSON，右键选择 Godot Aseprite Wizard 的导入命令，等待生成导入资源。

  5. 5

    添加动画节点

    将生成的场景拖入当前场景，按需求添加 AnimationPlayer、AnimatedSprite 或 SpriteFrames 节点，并连接对应动画资源。

  6. 6

    运行并检查播放

    在脚本中调用 AnimationPlayer 的播放方法，或设置 AnimatedSprite 的动画与 SpriteFrames；运行项目检查帧率、循环和缩放效果。

💡 实用技巧

  • 首次导入前先重启 Godot 并刷新文件
  • JSON 与 PNG 必须使用同名基础文件名
  • 循环属性可在导入设置中调整
  • 先用简单两帧动画验证流程

⚠️ 常见坑

  • Aseprite 路径错误会导致导出无响应
  • 漏掉 JSON 文件会造成动画无法导入
