Godot MCP 入门：接入 AI 完成首个场景

在 Godot 4.2+ 中安装并配置 Godot MCP Toolkit，让 AI 助手直接执行脚本、场景与试玩测试，产出可继续迭代的游戏原型。

关联工具GOgodot-mcp-toolkit官网 ↗
入门⏱ 约 20 分钟🎯 用 AI 创建并验证一个可玩的 Godot 场景
  1. 1

    准备 Godot 与项目

    使用 Godot 4.2 或更高版本创建项目并打开编辑器，确认项目能正常运行。后续让 AI 在此项目中操作，场景、脚本和测试产物都直接进入当前管线。

  2. 2

    安装 MCP 工具包

    从项目 GitHub 页面获取 Godot MCP Toolkit，按仓库说明在 Godot 中安装插件。安装后重新打开编辑器，检查插件是否启用以及相关服务是否成功启动。

  3. 3

    配置 AI 助手连接

    在支持 MCP 的 AI 编码助手中添加该工具包对应的 MCP 服务配置，连接当前 Godot 编辑器。先发送简单查询，确认助手能看到编辑器与项目上下文。

  4. 4

    让 AI 创建场景脚本

    向 AI 明确目标，例如创建玩家节点、移动脚本和简单交互，并要求使用工具包执行。检查生成节点与 GDScript，必要时继续对话，让 AI 修正逻辑和场景组织。

  5. 5

    在编辑器内试玩验证

    要求 AI 调用工具包运行试玩测试，观察控制、碰撞和场景切换是否符合描述。将失败信息反馈给 AI，让其修改脚本或节点，再次运行测试直至通过。

  6. 6

    整理可交付产物

    确认场景资源、GDScript 和测试结果已保存在项目中，再让 AI 汇总新增内容与操作步骤。提交这些文件即可进入版本管理、美术整合和正式迭代管线。

💡 实用技巧

  • 先用单场景小任务验证连接
  • 提示词写清节点、行为和验收条件
  • 每次只让 AI 修改一组对象
  • 测试通过后再提交版本

⚠️ 常见坑

  • Godot 版本低于 4.2 可能不兼容
  • 未启用插件或重启编辑器会导致连接失败

常见问题

Q：安装后 AI 看不到 Godot 项目怎么办？

先确认 Godot MCP Toolkit 插件已启用，并按仓库说明配置 MCP 服务。随后重启 Godot 与 AI 编码助手，发送简单查询，检查助手能否识别当前编辑器上下文。

Q：应该使用哪个模型完成操作？

教程未指定模型；选择支持 MCP 且能稳定调用工具的 AI 编码助手即可。先用小任务验证工具调用，再逐步扩展场景与测试任务。

Q：AI 生成的素材怎样进入游戏管线？

工具包主要面向脚本、场景、节点与测试。让 AI 把生成结果保存到当前 Godot 项目中，检查资源和脚本后提交版本，后续再接入美术、关卡与正式构建流程。

Q：它能完全替代人工测试吗？

不能把自动试玩当作完整验收。让 AI 先运行编辑器内测试并修复明确错误，再由开发者检查操作手感、关卡节奏、资源效果与目标平台表现。
