Godot Dear ImGui 入门：从安装到首个界面

面向 Godot 4 与 C++ 开发者，讲解插件安装、编译配置和示例界面调用，完成一个可交互的 Dear ImGui 面板。

关联工具IMimgui-godot官网 ↗
进阶⏱ 约 45 分钟🎯 在 Godot 4 中运行 Dear ImGui 调试面板
  1. 1

    准备编译环境

    安装 Godot 4、Git、支持 C++ 的编译工具链及 Python，并确认终端可执行 git、python 和项目所需的编译器。

  2. 2

    克隆插件项目

    在终端执行 git clone https://github.com/pkdawson/imgui-godot.git，将仓库保留到本地路径，避免修改原始 Git 历史。

  3. 3

    阅读并配置示例

    打开仓库 README 和 addons 目录，按当前 Godot 版本配置 C++ 插件路径、编译选项及入口文件；示例通常需要以 Godot C++ 项目运行。

  4. 4

    编译插件模块

    按仓库说明在终端运行对应构建命令，编译成功后确认生成库文件或项目可识别插件；失败时先检查编译器和依赖版本。

  5. 5

    创建 Godot C++ 项目

    在 Godot 项目管理器中新建 C++ 项目，将插件目录放入项目合适位置，并在项目设置或插件列表中启用对应 Dear ImGui 插件。

  6. 6

    显示并验证面板

    运行项目，在扩展或调试入口调用示例面板，确认窗口出现且能响应按钮、复选框等交互，再逐步替换为自己的 ImGui 控件。

💡 实用技巧

  • 先运行仓库示例，验证环境再改代码
  • 锁定 Godot 与插件版本避免接口不匹配
  • 使用 ImGui 调试工具定位渲染问题
  • 将面板代码与游戏逻辑解耦

⚠️ 常见坑

  • 普通 GDScript 项目不能直接使用 C++ 插件
  • 忽略平台工具链差异会导致编译失败
