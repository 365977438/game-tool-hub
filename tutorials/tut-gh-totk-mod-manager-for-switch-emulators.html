王国之泪模组管理入门：安装并运行首个模组

面向 Yuzu 模拟器玩家，讲解模组管理器的下载安装、游戏路径配置、模组导入与启停，以及运行验证的完整流程。

关联工具MO塞尔达传说：王国之泪模拟器 Mod 管理器官网 ↗
入门⏱ 约 20 分钟🎯 在 Yuzu 中安装并启用首个模组
  1. 1

    准备游戏与模拟器

    先安装 Yuzu，并合法备份《塞尔达传说：王国之泪》游戏文件。确认模拟器可正常启动游戏，再关闭 Yuzu 和游戏进程。

  2. 2

    下载模组管理器

    打开项目 GitHub 页面，进入 Releases 下载适配当前系统的发行版；若无现成安装包，可按 README 使用 Node.js 安装依赖并启动。

  3. 3

    配置 Yuzu 游戏目录

    启动管理器后，在设置或路径选项中选择 Yuzu 的游戏目录，并指定《王国之泪》所在文件夹。路径错误会导致模组无法识别或加载失败。

  4. 4

    导入本地模组

    在模组页面选择 Import 或添加按钮，导入已下载的模组压缩包或文件夹。若界面要求选择目标游戏，请确认条目为 TotK，并等待导入完成。

  5. 5

    启用并检查冲突

    在已安装列表中启用目标模组，检查其依赖模组与冲突提示。按列表建议停用不兼容项目，再执行应用、保存或部署操作。

  6. 6

    启动游戏验证

    重新启动 Yuzu 并运行《王国之泪》，检查模组功能是否生效。若画面异常，先在管理器中停用该模组，再根据日志定位缺失文件或版本问题。

💡 实用技巧

  • 模组压缩包应提前保留原目录结构
  • 先启用一个模组验证基础环境
  • 更新游戏后重新检查模组兼容性
  • 关闭游戏再部署可减少文件占用

⚠️ 常见坑

  • Yuzu 正在运行会导致部署失败
  • 直接放置模组文件可能绕过依赖检查
