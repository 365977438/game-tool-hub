UniCli 入门：从安装到首次自动化

了解 UniCli 的安装配置，并通过终端调用 Unity 执行项目编译、测试及编辑器命令，建立可复用的命令行工作流。

关联工具UNUniCli官网 ↗
入门⏱ 约 15 分钟🎯 能在终端中成功编译 Unity 项目并触发测试
  1. 1

    准备 Unity 环境

    安装 Unity Hub 与目标编辑器版本，并确认 Unity 可正常打开项目。终端需能调用 Unity 可执行文件，后续命令中的路径应按实际安装位置修改。

  2. 2

    获取并安装 UniCli

    打开 UniCli 的 GitHub 仓库，阅读 README 中的安装说明，将仓库克隆到本地，再按照文档要求完成构建或安装，并确认命令已加入 PATH。

  3. 3

    进入 Unity 项目

    在终端切换到包含 Assets、ProjectSettings 等目录的 Unity 项目根目录。先执行 UniCli 的帮助或版本命令，确认参数格式与当前环境无误。

  4. 4

    触发项目编译

    使用 UniCli 调用指定 Unity 编辑器并执行项目编译命令，检查输出日志及编辑器返回结果。首次执行可能较慢，应等待导入与编译结束。

  5. 5

    运行自动化测试

    在项目目录运行测试命令，必要时指定测试平台、过滤条件或报告输出位置。执行后查看终端结果与生成的测试报告，确认用例通过情况。

  6. 6

    执行编辑器命令

    根据 README 提供的方法，让 UniCli 调用编辑器内预置的命令或扩展入口。完成后检查场景、资源或项目设置是否按预期发生变化。

💡 实用技巧

  • 使用绝对路径调用 Unity，避免版本冲突
  • 先运行帮助命令确认参数名称
  • 为编译与测试分别保存日志
  • 将常用命令写成脚本复用

⚠️ 常见坑

  • Unity 路径或版本填写错误
  • 项目尚未导入完成便执行命令
