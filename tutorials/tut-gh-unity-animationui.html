Unity动画界面工具入门：制作第一个补间

从安装插件到配置 Motion 与 Tweening，掌握可视化编辑、拖放操作及代码调用方法，快速完成界面过渡动画。

关联工具UNUnity Animation UI官网 ↗
入门⏱ 约 20 分钟🎯 制作一个可播放的界面缩放与位移动画
  1. 1

    安装 Unity AnimationUI

    在 Unity 项目中打开 Window > Package Manager，进入 Add package from git URL，粘贴官方仓库地址 https://github.com/DhafinFawwaz/Unity-AnimationUI 并点击 Add。

  2. 2

    确认插件与示例

    等待 Unity 编译完成，在 Project 窗口搜索 AnimationUI，查看插件资源与示例。确认 Console 没有报错，并打开项目中的 Demo 场景了解基本用法。

  3. 3

    创建动画控制对象

    在 Hierarchy 中新建空物体并命名为 AnimationUI，将插件提供的 Motion 或 Tweening 组件挂载到该对象。按需添加 Canvas、EventSystem 和待动画的 UI 控件。

  4. 4

    配置补间参数

    选择目标 UI 对象，在动画组件中设置起止状态、持续时间、缓动曲线和播放时机。可先调整 Scale、Position、Alpha 等属性，并在预览区域检查效果。

  5. 5

    通过代码触发动画

    在按钮的 OnClick 事件中调用动画组件的公开方法，或在脚本中使用对应 API 播放 Motion/Tweening。确保脚本引用正确，并将触发方法绑定到按钮。

  6. 6

    测试并保存成果

    进入 Play Mode，点击按钮测试动画的播放、循环与结束状态。调整参数以避免遮挡和跳变，保存场景与 Prefab，形成可复用的界面动效。

💡 实用技巧

  • 先在 Demo 场景中熟悉组件结构
  • 用空物体集中管理界面动画
  • 优先调整缓动曲线改善节奏
  • 将常用动效保存为 Prefab

⚠️ 常见坑

  • 安装后等待脚本编译再操作
  • 确认目标对象已正确绑定到 Canvas
