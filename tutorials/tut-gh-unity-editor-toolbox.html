Unity编辑器工具箱入门：从安装到扩展工作流

了解 Unity Editor Toolbox 的安装方式、菜单入口和常用功能，并通过自定义属性与层级信息叠加，建立更高效的 Unity 编辑器工作流。

关联工具UNUnity 编辑器工具箱官网 ↗
入门⏱ 约 20 分钟🎯 完成插件安装并创建首个自定义属性工具
  1. 1

    确认项目环境

    打开 Unity Hub，进入目标项目的 Project Settings，确认 Unity 版本、渲染管线与项目模板；记录版本信息，便于后续排查兼容性问题。

  2. 2

    获取工具箱源码

    访问 GitHub 仓库 Unity-Editor-Toolbox，阅读 README 与 Releases；若提供 Unity Package 或预编译包，优先按说明下载，否则使用源码安装方式。

  3. 3

    安装到 Unity 项目

    在项目目录使用 Package Manager 的 Add package from git URL，或把仓库复制到项目 Packages 文件夹；等待 Unity 编译完成并检查 Console 是否报错。

  4. 4

    打开工具箱菜单

    在 Unity 顶部菜单寻找 Toolbox 或 Unity Editor Toolbox 入口，先打开 About、设置或帮助面板，确认插件已加载，并查看可用工具的分类位置。

  5. 5

    创建自定义属性

    新建继承相应自定义属性的脚本，在 Inspector 中标记字段并重新编译；回到对象 Inspector，填写该字段并检查属性绘制器是否正确显示。

  6. 6

    叠加层级信息

    在层级视图或工具箱设置中启用信息叠加，选择需要显示的标签、数值或状态字段；点击对象验证附加信息，便于批量检查场景数据。

💡 实用技巧

  • 安装前核对仓库的 Unity 版本要求
  • 先备份项目，避免批量改动受影响
  • 遇到编译错误先查看 Console 首条信息
  • 用测试场景验证层级叠加效果

⚠️ 常见坑

  • 不要把仓库根目录随意放入 Assets
  • 修改脚本后等待 Unity 完成重新编译
