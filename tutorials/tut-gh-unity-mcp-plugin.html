Unity MCP 入门：安装并创建首个场景

完成插件安装、MCP 客户端连接与基础配置，并让 AI 创建对象、添加组件及保存一个可运行的 Unity 场景。

关联工具UNUnity MCP Plugin官网 ↗
入门⏱ 约 20 分钟🎯 用 AI 创建并保存首个 Unity 场景
  1. 1

    准备 Unity 与 MCP 客户端

    安装 Unity Hub，并创建或打开一个 Unity 2022.3 及以上项目；同时准备支持 MCP 的 AI 客户端，如 Cursor。

  2. 2

    安装 Unity MCP 插件

    在 Unity 项目中打开 Window→Package Manager，进入 Add package from git URL，粘贴仓库地址并确认安装；随后重启 Unity 完成导入。

  3. 3

    启动本地 MCP 服务

    打开插件提供的 Unity 编辑器面板，按提示启动 MCP 服务，复制显示的本地地址、端口或连接参数，勿关闭对应 Unity 窗口。

  4. 4

    配置 AI 客户端

    在 Cursor 等客户端的 MCP 设置中新增服务器，填入 Unity 面板给出的连接信息，保存后测试连接，并确认客户端能识别 Unity 工具列表。

  5. 5

    创建并检查首个场景

    在 AI 对话框输入“创建一个包含相机、灯光和立方体的场景”，执行后切回 Unity，检查层级、场景视图及立方体组件是否正确。

  6. 6

    保存并运行验证

    让 AI 将场景保存为 Assets 下的场景文件，再点击 Unity 顶部 Play 按钮运行；确认对象正常显示，停止后手动保存场景。

💡 实用技巧

  • 先测试连接，再执行批量编辑器操作
  • 明确对象名称、位置和组件类型
  • 每次改动后切回 Unity 检查结果
  • 项目文件建议先提交 Git

⚠️ 常见坑

  • Unity 关闭后本地服务会中断
  • Git 包导入失败时检查网络与路径
