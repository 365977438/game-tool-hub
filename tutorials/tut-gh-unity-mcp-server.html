Unity MCP 入门：连接编辑器并创建物体

完成 Unity MCP Server 的安装、配置与连接，使用支持 MCP 的 AI 客户端创建场景物体、添加组件并查看运行结果。

关联工具UNUnity MCP 服务器官网 ↗
入门⏱ 约 25 分钟🎯 通过 AI 客户端在 Unity 场景中创建并配置物体
  1. 1

    准备 Unity 与 MCP 客户端

    安装兼容版本的 Unity Editor，并准备支持 MCP 的客户端，如 Cursor 或 Claude Desktop；确认 Unity 项目已创建且能够正常打开。

  2. 2

    安装 Unity MCP 包

    打开 Unity 项目的 Package Manager，切换到 Add package，搜索 unity-mcp-server 或对应仓库地址并安装；等待导入完成且无红色报错。

  3. 3

    启动 Unity MCP 服务

    在 Unity 中打开 MCP Server 窗口或相关菜单，点击启动服务；记录界面显示的启动命令、端口及连接方式，Unity Hub 用户需启用 Hub 连接功能。

  4. 4

    配置 MCP 客户端

    在客户端的 MCP 设置中新增服务器，按照 Unity 窗口显示的信息填写命令、参数和环境变量；保存后重新连接，状态应显示已连接。

  5. 5

    创建并操作场景物体

    在客户端中发送明确指令，例如“创建名为 Player 的空物体，添加刚体和胶囊碰撞体”；检查 Unity 场景层级与 Inspector，确认对象和组件已生成。

  6. 6

    测试构建与运行

    继续让 AI 修改物体位置、材质或脚本，并点击 Unity Play 验证效果；若需构建，先让 MCP 获取平台与输出路径，再执行对应构建任务。

💡 实用技巧

  • 先手动创建一个测试场景，便于确认 AI 操作生效
  • 指令中写明对象名、位置和组件，减少歧义
  • 构建前保存场景并确认目标平台
  • 每次修改后检查 Console 面板错误

⚠️ 常见坑

  • 客户端连接成功但 Unity 无响应时，先检查端口
  • AI 找不到新资源时，等待 Unity 完成资源导入
