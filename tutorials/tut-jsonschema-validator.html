JSON Schema 校验器入门：快速检查数据

通过粘贴 JSON 与 Schema，定位类型、必填字段、格式及嵌套错误，并学会编写常用自定义校验规则。

关联工具JSJSON Schema 校验器官网 ↗
入门⏱ 约 15 分钟🎯 能独立校验接口数据并定位错误
  1. 1

    打开校验页面

    在浏览器访问 jsonschemavalidator.net，确认页面已加载 JSON 输入区、Schema 输入区及校验结果区域，无需安装或注册。

  2. 2

    粘贴待校验 JSON

    将接口响应、配置文件或请求体粘贴到 JSON 数据输入区，并展开数据示例区；注意使用双引号，并保持逗号与括号配对。

  3. 3

    填写 JSON Schema

    在 Schema 输入区粘贴对应规则或选择示例 Schema，设置 type、properties、required 等字段，确保 Schema 描述的是实际数据结构。

  4. 4

    执行校验并查看结果

    点击 Validate 或对应的校验按钮，查看是否通过以及错误列表；结合错误路径定位具体对象、数组元素或缺失字段。

  5. 5

    增加格式与嵌套规则

    在 Schema 中加入 format、items、additionalProperties 等约束，检查邮箱、日期格式及数组内部对象；修改后重新运行校验。

  6. 6

    验证自定义规则

    使用 minimum、maximum、minLength、pattern、enum 等关键字限制数值、字符串和枚举值，放行合法样本并用反例确认规则生效。

💡 实用技巧

  • 先校验最小 Schema，再逐项添加规则
  • 错误路径通常可直接定位到具体数组项
  • 保留一份合法数据作为回归样本
  • 在线处理敏感数据前先移除隐私字段

⚠️ 常见坑

  • Schema 本身写错会导致结果不可靠
  • 字段名区分大小写且类型必须匹配
