Ogier 编辑器入门：制作第一张瓦片地图

从打开官网到导入、绘制并导出 JSON 瓦片地图，快速掌握 Ogier 的图层、对象放置、撤销重做与快捷键。

关联工具OGOgier 编辑器官网 ↗
入门⏱ 约 15 分钟🎯 制作并导出一张含多图层的 JSON 地图
  1. 1

    打开 Ogier 编辑器

    访问官网的 Ogier 页面，点击进入编辑器。先确认浏览器支持本地文件操作，再准备瓦片图片或 JSON 地图数据。

  2. 2

    新建并配置地图

    点击“新建”或创建项目，填写地图名称、宽高和瓦片尺寸。尺寸单位是格数，注意与所选瓦片图片的格数保持一致。

  3. 3

    添加瓦片资源与图层

    在资源或瓦片集面板中导入图片，按行列切分并标记碰撞等属性。随后创建地面、装饰等图层，并调整绘制顺序。

  4. 4

    绘制地图场景

    选择图层和瓦片，在画布中拖动连续绘制；按需使用矩形、填充等工具铺设地面，再用对象工具放置角色、出生点或触发器。

  5. 5

    调整对象与属性

    在选中对象后修改坐标、名称、类型及自定义属性。切换不同图层检查遮挡关系，确保对象所在层与碰撞规则符合关卡逻辑。

  6. 6

    导入检查并导出 JSON

    通过撤销重做和快捷键修正细节，再保存工程。点击导出，选择 JSON 格式并下载文件；重新导入可验证地图、图层和对象是否完整。

💡 实用技巧

  • 先用纯色地面块快速搭出关卡轮廓
  • 按功能拆分地面、装饰和碰撞图层
  • 定期导出 JSON，避免刷新丢失进度
  • 快捷键能显著加快重复绘制与切换

⚠️ 常见坑

  • 地图尺寸与瓦片集格数不匹配会导致错位
  • 对象放在错误图层会改变显示或碰撞效果
