Phaser 入门：从安装到第一个游戏

理解 Phaser 的核心结构与工作流，完成开发环境搭建，并用 JavaScript 制作一个可交互、可计分的网页小游戏。

关联工具PHPhaser官网 ↗
入门⏱ 约 30 分钟🎯 制作并运行一个可计分的网页小游戏
  1. 1

    安装开发环境

    打开官网并进入 Examples，下载 Node.js 与代码编辑器；在终端运行 node -v，确认 Node.js 已正确安装并可执行。

  2. 2

    创建项目目录

    在终端新建 phaser-demo 文件夹，进入目录后执行 npm init -y，再运行 npm install phaser，生成包含 Phaser 依赖的 package.json。

  3. 3

    建立游戏画布

    创建 index.html，引入 phaser.js，并在页面放置 id 为 game 的 div；随后新建 main.js，使用 new Phaser.Game 配置画布宽高、背景色和场景。

  4. 4

    编写首个场景

    在 main.js 中继承 Phaser.Scene，定义 preload、create、update 方法；create 中添加文本和矩形，让游戏元素显示在画布中。

  5. 5

    加入移动与交互

    使用 this.input.keyboard.addKeys 保存方向键引用，在 update 中读取按键并移动精灵；再用 this.input.on('pointerdown') 响应鼠标点击。

  6. 6

    运行并验证结果

    在项目目录执行 npm install，再运行 npx http-server -p 8080；浏览器打开 localhost:8080，测试移动、点击和计分显示。

💡 实用技巧

  • 用浏览器开发者工具查看报错信息
  • 先使用固定尺寸画布便于调试
  • 场景切换可拆分关卡与界面
  • 素材放入 assets 并统一管理路径

⚠️ 常见坑

  • 脚本顺序错误会导致 Phaser 未定义
  • 精灵坐标与刚体中心可能不一致
