Roo Code 入门：从安装到首个游戏原型

面向使用 AI 开发游戏的开发者，演示在 VS Code 中配置 Roo Code、选择本地或云端模型，并让代理读写项目、运行命令，最终产出可运行的游戏原型。

关联工具RORoo Code官网 ↗
入门⏱ 约 20 分钟🎯 生成并运行一个可交互游戏原型
  1. 1

    安装并打开项目

    在 VS Code 扩展市场搜索并安装 Roo Code，打开游戏项目根目录；先备份代码，并确认终端、构建脚本和资源目录完整。

  2. 2

    配置模型与权限

    打开 Roo Code 侧边栏，在模型设置中选择云端模型或填写本地模型地址；配置 API 密钥，并审查自动执行终端命令的权限范围。

  3. 3

    描述游戏任务

    切换到合适模式，新建任务并说明玩法、引擎、美术资源和验收标准，例如：“用现有引擎制作单场景躲避游戏，支持暂停与计分”。

  4. 4

    检查并应用改动

    让代理先分析项目并列出计划，再逐项审阅文件差异；接受代码后检查场景、脚本与资源配置，必要时要求代理修正。

  5. 5

    运行命令并调试

    在代理面板执行构建、启动或测试命令，读取控制台报错；把错误日志粘贴回任务，让 AI 定位问题并迭代修复。

  6. 6

    导出可交付原型

    完成验收后，让代理整理启动说明、参数配置和已知问题；提交源码与资源，并运行一次全新克隆后的构建流程。

💡 实用技巧

  • 先让代理分析，批准计划后再改代码
  • 每次只交付一个明确、可验收的功能
  • 保留版本控制，便于比较和回退改动
  • 本地模型适合敏感项目，云端模型更省配置

⚠️ 常见坑

  • 未审查权限就让代理执行任意终端命令
  • 任务描述过于笼统，容易生成不可玩原型
