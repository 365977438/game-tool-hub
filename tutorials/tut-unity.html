Unity 入门：从安装到第一个场景

本教程带你完成 Unity 安装、创建项目、搭建场景、编写 C# 脚本并运行交互原型，最终得到一个可点击触发反馈的小项目。

关联工具UNUnity 引擎官网 ↗
入门⏱ 约 30 分钟🎯 制作一个可点击响应并显示文字的场景
  1. 1

    安装并启动 Unity Hub

    前往 unity.com 下载 Unity Hub，安装后登录账号。在 Hub 的“安装”页选择所需 Unity 版本与 Windows、macOS 等目标平台组件，再点击“安装”。

  2. 2

    创建 2D 项目

    在 Hub 点击“新建”，选择“2D”模板，填写项目名称与保存位置，确认 Unity 版本后点击“创建”。首次打开会导入资源，等待右下角进度结束。

  3. 3

    搭建基础场景

    打开“Game”窗口确认视图，将顶部视图切换为“2D”。在 Hierarchy 点击“Create → 2D Object → TextMeshPro”，输入文字，并在 Scene 窗口调整位置、大小与颜色。

  4. 4

    添加点击区域

    在 Hierarchy 右键选择“Create → UI → Button”，将其拖入文本下方。在 Inspector 的 Text 字段输入按钮文字，并用 Rect Transform 调整宽度、高度及与文本的间距。

  5. 5

    编写 C# 交互脚本

    在 Project 窗口点击“Create → C# Script”，命名为 ButtonEffect。双击脚本，在 TextMeshProUGUI 类中引用文字对象，编写点击按钮后改变其文本颜色的方法。

  6. 6

    绑定事件并运行

    将脚本挂到 Button 对象，拖入文字引用。在 Inspector 的 Button 组件中点击“+”，把 Change Color 方法加入 On Click 列表，点击 Play 测试按钮效果。

💡 实用技巧

  • 定期使用 Ctrl+S 保存场景与项目
  • 先在 Console 查看红色报错信息
  • 组件排序可让核心脚本更易查找
  • 使用版本控制备份项目文件

⚠️ 常见坑

  • 漏绑事件会导致按钮点击无响应
  • 脚本类名与文件名不一致会报错
