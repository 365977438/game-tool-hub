VS Code 入门：从安装到调试项目

完成 VS Code 安装、文件夹管理与扩展配置，并用内置终端、调试器和 Git 视图完成一次代码修改、运行与版本提交。

关联工具VSVS Code官网 ↗
入门⏱ 约 20 分钟🎯 独立创建并调试一个多文件夹项目
  1. 1

    下载并安装编辑器

    打开官网，点击“Download”，选择 Windows、macOS 或 Linux 安装包；按系统提示完成安装，启动 VS Code。

  2. 2

    创建并打开工作区

    选择“文件→打开文件夹”，定位项目目录并打开；在侧边栏可同时管理多个文件，点击“文件→将文件夹添加到工作区”可并行管理项目。

  3. 3

    安装所需扩展

    点击左侧“扩展”图标，搜索语言名称、格式化工具或框架插件；点击“安装”，必要时重启窗口，随后按需配置主题和快捷键。

  4. 4

    编辑代码并使用智能补全

    新建文件并输入代码，利用语法高亮、括号匹配和悬浮提示检查内容；按 Tab 接受补全，在“文件→首选项→设置”中启用保存时格式化。

  5. 5

    运行终端与任务

    使用“终端→新建终端”进入当前项目目录，执行 npm、Python 或其他命令；在“终端→运行任务”中定义构建、测试等任务并保存常用操作。

  6. 6

    调试并使用 Git

    在代码行号旁点击断点，按 F5 选择调试配置并启动；点击“源代码管理”图标查看差异，填写提交信息后提交，首次使用需先初始化仓库。

💡 实用技巧

  • 按 Ctrl+Shift+P 打开命令面板
  • 拖动侧边栏可快速调整工作区
  • 使用用户设置覆盖默认编辑器行为
  • 为常用任务设置统一运行入口

⚠️ 常见坑

  • 不要把终端当前目录与项目目录混淆
  • 提交前检查差异，避免误改生成文件

常见问题

Q：下载安装时应该选择哪个系统版本？

打开 VS Code 官网并点击“Download”，根据当前设备选择 Windows、macOS 或 Linux 安装包，然后按系统提示完成安装，启动后即可打开项目文件夹。

Q：怎么同时管理多个项目文件夹？

先通过“文件→打开文件夹”打开首个项目，再选择“文件→将文件夹添加到工作区”，即可在侧边栏并行管理多个项目目录，并分别编辑其中的文件。

Q：代码修改后怎样运行、调试并提交？

先用“终端→新建终端”进入项目目录运行命令，再点击行号旁设置断点并按 F5 启动调试；最后在“源代码管理”视图检查差异，填写提交信息并提交，首次使用需先初始化仓库。
